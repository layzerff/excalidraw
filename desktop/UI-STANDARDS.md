# UI 对齐规范

- 同一行操作共用高度、字号、行高和内边距；图标与文字以 flex 居中，SVG 使用 display:block，不依赖基线或手工 top 偏移。
- 主窗口顶部操作按钮统一 30px 高、12px 字号、18px 行高、图文间距 6px。主题选择与同一行按钮垂直居中。
- 原生绘图工具栏扩展必须复用 ToolIcon/ToolIcon__icon、原生 --default-button-size 和 --default-icon-size；按钮 margin/padding 归零、box-sizing:border-box；保持同尺寸图标视口。
- 标题旁说明按钮使用 24×24px 点击区、19px 图标，按钮和标题共用中线；不继承普通按钮的内边距或最小高度。
- 所有主题（含 WeChat、Discord）沿用以上布局度量，只通过主题配色表达状态。验证截图外，检查工具栏图标、顶部按钮、说明图标的中心坐标和文字字号。
- 绘图属性优先沿用官方组件的面板，避免重新绘制一套近似控件。

- 工作区保存/另存为、打开文件与搜索共用 30px 行高，相邻行间隔 6px；搜索至根目录间隔 8px，六种主题保持一致。
