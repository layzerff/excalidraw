# 修改记录

## 2026-10-18 · Windows x64 构建

- 基于当前版本生成 NSIS 安装版与免安装单文件 EXE，目标运行时为 Windows x64 Electron 44.9.0。
- 两个 EXE 的 NSIS 嵌入包完整性检查通过；应用主程序为 x86-64 PE，app.asar 包含主进程、预加载脚本、238 个字体资源及许可证声明。
- 未提供 Authenticode 签名，尚未在 Windows 实机启动；macOS 回归结果不替代 Windows 验证。免安装版仍默认将工作区存储在 `%APPDATA%/Local Canvas/`。

## 2026-10-18 · 保存布局与演示停留时间

- N26：工作区使用固定两行两列，第一行“＋白板、＋文件夹”，第二行“保存、另存为”，不再依赖自动折行。
- N27：自动演示每页停留可选 1/2/3/5/10/15/30 秒，默认 3 秒；移动时长仍独立选择 0.5/1/1.5/2 秒。播放中更改停留值会从当前页重新计时。
- 临时画笔按场景建立独立历史，避免快速自动翻页后的撤销记录残留；跨页保留颜色、粗细、透明度和背景偏好。

## 2026-10-18 · 演示与保存位置

- N20：底部增加“图层”，演示内可打开场景列表、拖拽排序、右键改名；标题原位编辑，取消编辑不退出全屏。
- N21：增加“保存位置”和“另存为”。显示数据库及自动备份路径；迁移使用 SQLite 一致性备份及备份文件复制，目标非空拒绝覆盖。原位置保留，迁移后锁定编辑直到重启，配置不可用时明确报错而非新建空白库。
- N22–N23：编辑侧栏固定 0.5 秒。演示手动/自动移动时长可选 0.5、1、1.5、2 秒；自动模式停留 3 秒，到末页停止，打开图层或画笔时暂停。
- N24：重复点击当前白板不再清空编辑器 API；实际加载文档使用独立挂载序号，缺失 API 时可重新挂载恢复，演示入口等待编辑器准备完成。
- N25：每次进入演示从当前排序第一项开始，不沿用上次浏览场景。

## 2026-10-17 · 场景交互与统一导出

- N13–N16：移除场景栏素材库按钮和总数，取消常驻改名/重框/上移/删除按钮，改由右键菜单进入；改名在标题原位完成，Enter/失焦提交，Esc 取消，支持双击标题。
- N17：演示临时画笔改用独立的官方 Excalidraw 实例，复用原生 freedraw 笔迹与描边、背景、宽度、透明度面板；不再使用手写 SVG 折线和自定义颜色/宽度控件。临时实例不接入文档自动保存，翻页清空元素和历史，退出销毁。
- N18：顶部导出按钮统一为右上角一个导出图标。支持框选区域 PNG、SVG、PDF，整板及按场景分页 PDF；完整文档与标准 Excalidraw 导出明确保留整张白板。
- 本地素材库使用画布原生入口或拖入 `.excalidrawlib`，导入、去重和文档持久化继续保留。
- N19：自动保存不再受平移、缩放和场景导航触发，内容编辑沿用最近一次手动保存的视图。保存按钮放在左侧工作区“＋白板、＋文件夹”后，配合 Cmd/Ctrl+S 提交内容及当前视图；关闭/切换仍只提交待保存内容。重启恢复最近手动保存的视图。

## 2026-10-17 · macOS 安装包修正

- 修复桌面包保留 Electron 不完整签名、导致系统提示“已损坏”的问题。在打包归档前补齐本地 ad-hoc 签名并进行深度严格校验。
- 此签名用于验证包完整性，不具备 Apple Developer ID 信任或公证。下载后仍可能需要在 macOS 隐私与安全设置中批准打开。

- N01–N04：增加 0.5 秒移动时长、移除尺寸文字、压缩场景条目、增加拖动手柄与上下半区插入提示、首末位落点及边缘滚动。
