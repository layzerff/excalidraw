# 修改记录

## 0.5.0 · 正式版

本次将 0.4.1 之后的本地预览功能汇总为正式版本，版本号统一为 0.5.0。首页只展示功能与 25 段真实全彩 WebP 演示，详细历史集中在本清单。

- **本地文档**：根目录/文件夹右键新建、就地改名/移动、拖拽迁移与排序；自定义、名称、创建时间三种排序，清晰层级和祖先路径高亮。
- **保存与恢复**：内容自动保存，浏览不写入；Cmd/Ctrl+S 同时保存当前视图，打开/另存为独立文件并查看路径，外部冲突保护、工作区迁移、备份恢复、回收站与确认清空。
- **场景管理**：框选、当前视图、独立元素或组合三种入口；自动跟随、重框解除、重建跟随、关联删除提示/偏好及本次会话撤销恢复；原位标题、拖拽排序、Shift 批量确认删除。
- **演示**：首页开始，平滑导航可打断；手动/自动 0.5–2 秒移动与独立停留时长，循环开关、图层面板排序/改名；原生风格临时画笔，翻页/退出清除且不写入文档。
- **绘图增强**：原生四档外增加 10–100% 相对字号滑块、46px 数字输入和 Tab 编辑；绑定文字按容器比例，新文字继承字号。填充密度 10–200%，斜线/交叉实时调节、实心保持铺满；同类继承且不建立密度专用撤销。球标保持正圆、递增/手动起点、尺寸/字号继承。框选纵向、横向、阵列等距整理并可一键加入跟随场景。
- **导航与搜索**：中键双击全览不受固定最低比例限制，拖动定位、再双击恢复编辑比例、右键保留视图；滚轮连续按比例缩放，设置按 5% 档位选择步长。独立画布文字/全拼/首字母/混合拼音搜索、高亮与定位选中。
- **素材库**：逐项名称/标签/图元文字搜索本地和在线内容，分区结果与渐进加载；两个折叠根目录、清晰缩进、冻结标题、可拖宽及 Ctrl＋滚轮自动矩阵。官方在线包预览、拖入、离线保存、浏览器下载/确认安装回传；本地分类文件夹、多选移动/导出/确认删除、素材位置查看和保留原文件的安全迁移。素材跨文档共享，旧文档合并一次；完整备份包含分类结构。
- **网页与视频**：通用 HTTPS 与 NAS 页面，按文档会话确认加载、沙箱/本地文件隔离与浏览器打开；YouTube/Bilibili 专门适配，编辑/演示可播放、暂停与调整进度，切场景自动暂停。
- **WebDAV**：配置收拢设置，说明气泡、实际连接圆点/详情、手动上传/恢复；加密保存凭据，备份不携带密码，不进行双向自动合并。
- **界面与更新**：六主题、中英 UI、原生工具栏拖拽顺序、左右侧栏隐藏/拖宽、独立只读、统一图标/字号/焦点框；设置保存反馈，GitHub 正式/测试渠道检查、可选下载与 SHA-256 校验。更新后的完整 Mac 图标使用系统圆角模拟，未安装 Xcode。
- **导出与 NAS**：统一入口、指定区域 PNG/SVG/PDF、整板与场景分页 PDF、完整可编辑文档；NAS 浏览器版使用服务端 SQLite、登录保护与持久化，提供 Node / Docker / 群晖配置文件。
- **演示文档**：以用户 new 白板只读副本制作 25 段全彩 WebP；字号/填充主体居中，视频独立分区并居中放大，连续滑块配指针高亮；不保留 GIF 副本，不改原白板。

验证和边界详见 VALIDATION.md：Windows/真实 NAS、不同站点及超大白板仍待更多实机验收；Mac 未公证、Windows 未签名；临时画笔快捷键撤销历史偶发性继续跟踪。
