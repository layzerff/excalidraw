## 2026-10-20 · 0.2.0 文件管理与布局

- 根目录和文件夹右键新建白板/文件夹，移除常驻新建按钮；备份、恢复、回收站及迁移收进折叠“工作区管理”。
- 文件夹名称 14px/650，文件条目 12px；增加文件夹图标、28px 展开按钮、折叠状态持久化。
- 三点/右键菜单在点击处展开，可改名、选择目标文件夹、移入回收站；拖动支持文件夹和根目录，防止文件夹移入自身或子目录。
- 左右侧栏支持拖动宽度与键盘方向键微调，宽度记忆到本机设置。
- “打开文件”通过系统窗口选择 `.canvas.json` / `.excalidraw`，保留原文件关联；手动保存同时记录视图并写回。另存为选择新位置并关联，新文件包含场景；原生格式通过 Local Canvas 扩展字段保留场景和素材库。
- 自动保存仍仅保存内容到本机 SQLite 恢复副本，不因平移写入，也不会自动修改外部文件。原文件被外部修改或移动时拒绝覆盖，提示另存为；关联不随备份导入到其他文档。
- 标题旁“文件信息”查看文件路径及本机恢复副本位置，左侧不常驻显示路径。逻辑文件夹移动/回收不会移动或删除磁盘上的关联文件。
- 桌面包与界面版本统一升级为 0.2.0。

## 2026-10-18 · Windows x64 构建

- 基于当前版本生成 NSIS 安装版与免安装单文件 EXE，目标运行时为 Windows x64 Electron 44.9.0。
- 两个 EXE 的 NSIS 嵌入包完整性检查通过；应用主程序为 x86-64 PE，app.asar 包含主进程、预加载脚本、238 个字体资源及许可证声明。
- 未提供 Authenticode 签名，尚未在 Windows 实机启动；macOS 回归结果不替代 Windows 验证。免安装版仍默认将工作区存储在 `%APPDATA%/Local Canvas/`。

- N26：工作区使用固定两行两列，第一行“＋白板、＋文件夹”，第二行“保存、另存为”，不再依赖自动折行。

## 2026-10-17 · 场景交互与统一导出

- N13–N16：移除场景栏素材库按钮和总数，取消常驻改名/重框/上移/删除按钮，改由右键菜单进入；改名在标题原位完成，Enter/失焦提交，Esc 取消，支持双击标题。
