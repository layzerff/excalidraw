## 2026-10-25 · 0.3.0 GitHub 风格 UI 与 Mac 图标占比

- 统一为 GitHub/Primer 风格浅色主题：白色画布、浅灰侧栏、细边框、蓝色选中与焦点、绿色主操作和红色危险操作；整理旧 CSS 的重复覆盖。Excalidraw 原生控件采用同色系外观变量，不改写画布元素样式和字体数据；原生深色画布控件不强行套浅色变量。

- Mac ICNS 使用专用 832px 图像/1024px 画布布局，补齐常规小尺寸 ICNS 资源；在 Finder 中与系统计算器并排检查，显示面积接近且不再有明显的二次底板缩小。应用内与 Windows 仍使用原透明四角 Logo，不改变图形设计。生成脚本新增 mac-icon.swift，产物提交仓库，Windows 打包不需要 Swift。
- 版本升为 0.3.0。功能与验证状态见 VALIDATION.md；默认分支仅同步说明和实机截图。
