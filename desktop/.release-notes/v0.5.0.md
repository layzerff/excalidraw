# Local Canvas v0.5.0

基于官方 MIT Excalidraw React 组件的本地优先无限画布正式版本。

- 本地文档/文件夹与排序、自动保存/手动视图保存、独立文件、备份恢复和回收站。
- 三种场景、元素自动跟随、重建绑定、拖拽排序、批量删除和全屏循环演示。
- 原生临时画笔、相对字号滑块、填充密度、自增球标和等距自动整理。
- 全览快速定位、文字/拼音搜索、六主题、中英界面与工具栏排序。
- 本地/在线素材逐项搜索、文件夹管理、缩略图自动排列、Ctrl＋滚轮调大小和保存位置迁移。
- 通用 HTTPS 网页及 YouTube/Bilibili 视频、加载授权、专门视频切场景暂停。
- WebDAV 手动备份、连接状态和加密凭据；NAS 网页版与部署文件。
- 正式/测试更新渠道检查、下载校验；完整功能演示 WebP 动图 见仓库首页。

文件：macOS Apple Silicon ZIP、Windows x64 安装版/免安装版、NAS Web ZIP，附 SHA256SUMS.txt。

说明：Mac 为临时完整性签名，未做 Developer ID 公证；Windows 未做 Authenticode 签名，Windows 与真实 NAS 仍需实机验收。PDF 为栅格页面，不携带交互网页/视频。网站可限制嵌入；通用网页不保证统一自动暂停。WebDAV 为手动备份，不是双向同步。演示画笔键盘撤销曾出现偶发失败，保留跟踪，不因部分回归通过宣称完全消失。

许可证：MIT 及第三方依赖、字体声明随包提供；不连接 Excalidraw+。
